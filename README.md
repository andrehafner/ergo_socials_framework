# Ergo Socials Framework

Community governance and moderation framework for the Ergo ecosystem.

---

## Documentation

### [Moderation Rules](docs/moderation-rules.md)
Core community rules covering conduct standards, discussion guidelines, prohibited behaviors, and enforcement procedures. Applies to all official Ergo-managed social spaces including Discord, Telegram, and forums.

### [Admin Charter](docs/admin-charter.md)
Standards and expectations for Sigmanauts administrators. Covers authority scope, accountability, collective decision-making, emergency powers, and professional conduct requirements.

### [Admin Application Framework](docs/admin-application-framework.md)
Prerequisites and evaluation criteria for admin/moderator applicants. Includes baseline requirements, disqualifying factors, and trial period details.

### [Dispute Resolution Flowchart](docs/dispute-resolution-flowchart.md)
Visual guide to the dispute resolution process, from initial issue through formal review and decision.

### [Dispute Submission Process](docs/dispute-submission-process.md)
Instructions for submitting formal disputes to the admin team, including contact information and what to include in your submission.
